CardCare Studio V3 — ชุดสำหรับนำขึ้นเว็บแบบเดโม

ไฟล์ index.html เป็นเว็บต้นแบบแบบหน้าเดียว สามารถนำขึ้น static hosting เพื่อให้เปิดผ่านลิงก์ได้

ข้อจำกัดสำคัญ:
- ยังไม่มีฐานข้อมูลหรือระบบล็อกอินจริง
- ข้อมูลที่กรอกไม่ได้บันทึกลงเซิร์ฟเวอร์อย่างถาวร
- รูป/วิดีโอเป็นเพียงการแสดงตัวอย่างในเบราว์เซอร์ ไม่ได้อัปโหลดเข้าระบบหลังบ้าน
- อย่าใช้รับข้อมูลลูกค้าจริงหรือหลักฐานการ์ดจริงจนกว่าจะเชื่อม backend, storage, access control และ privacy/security แล้ว

การเปิดเป็นเดโมออนไลน์อย่างรวดเร็ว:
1. เปิดบริการ static hosting เช่น Netlify Drop หรือ Cloudflare Pages
2. อัปโหลดไฟล์ index.html (หรือแตก ZIP นี้แล้วอัปโหลดโฟลเดอร์)
3. ระบบโฮสต์จะสร้าง URL สำหรับเปิดเว็บเดโม

การทำระบบใช้งานจริงต้องเพิ่ม backend/API, ฐานข้อมูล, ระบบอัปโหลดรูปและวิดีโอแบบ private, ลิงก์เคสเฉพาะลูกค้า, ระบบล็อกอินพนักงาน และการบันทึกประวัติการดำเนินการ
